# Electric Vehicle (EV) Adoption Across Cities Dashboard

## Project Overview

This project analyzes the **adoption of Electric Vehicles (EVs) across different cities and regions** using an interactive dashboard built in **Microsoft Excel**.

The dashboard provides insights into EV population growth, regional distribution, and adoption trends to better understand the transition toward sustainable transportation.

---

## Technologies Used

* Microsoft Excel
* Data Cleaning & Transformation
* Pivot Tables
* Pivot Charts
* Interactive Dashboard Design

---

## Dataset

The dataset contains historical records of Electric Vehicle registrations across different cities and states, including:

* EV Population
* City / County
* State
* Vehicle Type
* Model Year
* Adoption Trends Over Time

---

## Dashboard Features

The Excel dashboard includes several interactive visualizations such as:

* EV adoption trends over time
* City-wise and state-wise EV distribution
* Vehicle type analysis
* Growth trends in electric vehicle adoption
* Interactive filters using slicers

---

## Key Insights

The dashboard helps identify:

* Cities with the highest EV adoption
* Growth trends in electric vehicle usage
* Regional differences in EV adoption
* Changes in EV popularity over different years

---

## Project Goal

The goal of this project is to demonstrate how **data visualization and dashboarding techniques in Excel** can be used to analyze and communicate trends in **electric vehicle adoption**.
